# 晒窗 · ShaiWin

> **本项目已停止维护。**
>
> 晾衣绳（把窗口像衣服一样挂在绳子上）的设计在实际使用中并不实用，因此这一方向不再继续。如果你需要更好的窗口切换工具，请移步 **[ShaiZero](https://github.com/19y/ShaiZero)**（[在线主页](https://19y.github.io/ShaiZero/)）。本仓库仅作存档保留。

晒窗是一个 Windows 窗口快速切换工具：按住 `Alt` 在桌面任意位置拖出鼠标，轮盘就在光标处展开，指针停在某一格松手，对应窗口便切到前台。早期版本曾尝试把窗口像晾衣服一样挂在绳子上，但这一交互并不实用，相关设计已经放弃。
